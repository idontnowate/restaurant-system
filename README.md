# 🍽 نظام إدارة المطاعم

نظام عربي شامل لإدارة المطاعم يُباع لعدة مطاعم: كل مطعم بحساباته وبياناته واشتراكه، مع لوحة للمزوّد (صاحب البرنامج) لإدارة الاشتراكات.

## المزايا
- **حسابات ودخول:** كل موظف يدخل باسم مستخدم وكلمة مرور. المدير ينشئ حسابات موظفيه ويحدد دور كل واحد (مدير، كاشير، ويتر، طباخ، سائق) وما يظهر له.
- **لوحة المزوّد** (`provider.html`): إنشاء مطعم مع حساب مديره، اشتراكات (تجربة، شهر، 3، 6، سنة)، تجديد، إيقاف، إعادة تعيين كلمات المرور، آخر نشاط لكل مطعم. عند انتهاء الاشتراك يتوقف المطعم وتبقى بياناته.
- **نقطة البيع:** صالة / سفري / توصيل، بحث، ملاحظة لكل صنف، خصومات بحد أقصى، خدمة وضريبة وتقريب، طرق دفع متعددة، «إرسال للمطبخ والدفع لاحقاً» للصالة، بيانات الزبون والعنوان للتوصيل.
- **الطاولات والحساب:** طوابق وأقسام، حساب الطاولة يجمع كل طلباتها، خصم، طباعة الحساب، دفع وتحرير الطاولة، نقل الطلبات لطاولة أخرى، الحجوزات.
- **شاشة المطبخ:** الطلبات تصل فوراً مع عداد وقت وتنبيه صوتي وطباعة تلقائية للتذاكر.
- **تطبيق الويتر:** للموبايل — الطاولات، الأصناف بالصور، ملاحظات، إرسال للمطبخ، تنبيه عند الجاهزية، طلب الحساب.
- **المنيو:** صور الأطباق (تُرفع مرة وتُحفظ على الأجهزة)، التصنيفات، الأسعار، الوصفات، إيقاف صنف، التكلفة ونسبة الربح.
- **المخزون:** مواد خام بوحدات، خصم تلقائي حسب الوصفة (ويُرجع عند الإلغاء)، استلام بضاعة، تسجيل الهدر بسببه، تنبيهات النقص.
- **العملاء:** سجل الزبائن، نقاط ولاء تلقائية، ملاحظات.
- **الصندوق:** الوردية الحالية، النقد المتوقع، عدّ النقد والفرق، تقرير X وإغلاق الوردية بتقرير Z مطبوع.
- **المصاريف:** إيجار، رواتب، كهرباء، مولدة…، مع خيار «من درج الكاشير».
- **التقارير:** حسب الفترة (اليوم، أمس، 7 أيام، 30 يوماً، الشهر، فترة محددة): المبيعات، الأرباح الصافية بعد المواد والمصاريف والهدر، حسب الدفع/النوع/التصنيف/الموظف/الساعة، الأصناف الأكثر مبيعاً، تصدير Excel (CSV).
- **سجل العمليات:** الدخول، الإلغاءات وأسبابها، الخصومات، تعديل الأسعار، الموظفين، إغلاق الورديات.
- **الطباعة:** فاتورة الزبون وتذكرة المطبخ لطابعات 80 و58 ملم، مع الشعار.
- **يعمل كتطبيق** على الموبايل والكمبيوتر، ويفتح بدون إنترنت. 4 مظاهر.
- **التخصيص الكامل (الإعدادات):**
  - **الشكل:** اللون الرئيسي للمطعم، الزوايا، المسافات، حجم بطاقات الأصناف، إخفاء الصور، مكان السلة، ترتيب صفحات القائمة وإخفاؤها، أقسام لوحة التحكم.
  - **طريقة العمل:** طرق دفع خاصة بالمطعم (اسم، لون، أيقونة، نقد في الدرج)، أسماء أنواع الطلبات والخدمة لكل نوع، الضريبة مضافة أو داخل السعر، ترقيم الطلبات (بادئة، رقم البداية، يومي)، قوائم المصاريف والهدر والوحدات.
  - **الفاتورة:** إظهار أو إخفاء كل سطر، الرقم الضريبي، نص إضافي، حجم الخط، عدد النسخ، حجم تذكرة المطبخ، إرسال الفاتورة واتساب.
- **باقات المزوّد:** لكل مطعم باقة (أساسية، متقدمة، كاملة، مخصصة) تفتح أو تغلق الميزات، ورسالة من المزوّد تظهر في لوحة تحكمه.

## التشغيل على الإنترنت (للبيع لعدة مطاعم)
1. **قاعدة البيانات (مرة واحدة، وعند كل تحديث):** في مشروع Supabase الخاص بالمطعم ← SQL Editor ← الصق `supabase/restaurant-sync.sql` ← Run.
2. **حساب المزوّد (مرة واحدة):** في SQL Editor:
   ```sql
   select rms_provider_create('اسم_المستخدم', 'كلمة_مرور_قوية', 'اسمك');
   ```
3. افتح `https://idontnowate.github.io/restaurant-system/provider.html` وادخل بحساب المزوّد، ثم «＋ مطعم جديد».
4. أرسل بيانات الدخول لمدير المطعم (زر واتساب جاهز). يدخل من `https://idontnowate.github.io/restaurant-system/` ويضيف موظفيه من صفحة «الموظفين».

رابط مشروع Supabase ومفتاحه العام (Publishable key) في `CLOUD` داخل `prototype/core.js`. لا تضع مفتاح secret أو service_role في الكود أبداً.

يُنشر مجلد `prototype` تلقائياً على GitHub Pages مع كل رفع على `main`.

## التشغيل داخل المطعم بدون إنترنت (server.py)
يحتاج فقط [Python 3](https://www.python.org/downloads/) بدون أي مكتبات إضافية.

```bash
py server.py
```
أو انقر مرتين على `تشغيل-الخادم.bat` على ويندوز. ثم افتح على أي جهاز بنفس شبكة الواي فاي:
- لوحة الإدارة: `http://<عنوان-الجهاز>:8080/`
- تطبيق الويتر: `http://<عنوان-الجهاز>:8080/waiter.html`
- رموز QR للموبايلات: `http://<عنوان-الجهاز>:8080/connect.html`

في هذا الوضع لا توجد حسابات (يختار الموظف اسمه)، والبيانات تُحفظ في `data/state.json`.

## هيكل المشروع
| الملف | الوصف |
|---|---|
| `prototype/login.html` | تسجيل دخول الموظفين |
| `prototype/admin.html` | لوحة الإدارة ونقطة البيع والمطبخ والتقارير |
| `prototype/waiter.html` | تطبيق الويتر للموبايل |
| `prototype/provider.html` | لوحة المزوّد: المطاعم والاشتراكات |
| `prototype/connect.html` | رموز QR لربط الموبايلات |
| `prototype/core.js` | البيانات والمزامنة والحسابات والطباعة |
| `prototype/theme.css` | المظاهر والعناصر المشتركة |
| `prototype/pwa.js`، `sw.js`، `*.webmanifest`، `icons/` | التثبيت كتطبيق والعمل بدون إنترنت |
| `prototype/vendor/` | مكتبة رموز QR (محلية لتعمل بدون إنترنت) |
| `supabase/restaurant-sync.sql` | قاعدة البيانات: المطاعم، الحسابات، المزامنة، الصور، الأرشيف، السجل |
| `server.py` | خادم محلي يربط الأجهزة داخل المطعم بدون إنترنت |
| `.github/workflows/pages.yml` | النشر التلقائي على GitHub Pages |
| `docs/restaurant-needs.md` | تحليل احتياجات المطاعم وخطة البناء |
