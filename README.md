# 🍽 نظام إدارة المطاعم

نظام عربي شامل لإدارة المطاعم: نقطة بيع، شاشة مطبخ، طوابق وأقسام وطاولات، منيو بالصور، مخزون مرتبط بالوصفات، صلاحيات للموظفين، وتطبيق للويتر يرسل الطلبات مباشرة إلى المطبخ.

## المزايا
- **نقطة البيع:** صالة / سفري / توصيل، خصومات، خدمة وضريبة، طرق دفع متعددة، إضافة صنف جديد مباشرة.
- **شاشة المطبخ:** الطلبات تصل فوراً من الكاشير والويتر مع عداد وقت وتنبيه صوتي.
- **الطاولات:** طوابق متعددة، كل طابق فيه أقسام بأسماء (صالة رئيسية، عوائل، VIP…)، إضافة وحذف الطاولات.
- **تطبيق الويتر:** للموبايل — اختيار الطاولة والأصناف مع ملاحظات، إرسال للمطبخ، وتنبيه عند جاهزية الطلب.
- **المنيو:** صور الأطباق، التصنيفات، الأسعار، إيقاف صنف مؤقتاً، حساب التكلفة ونسبة الربح.
- **المخزون:** خصم تلقائي حسب وصفة كل صنف، تنبيهات النقص.
- **الصلاحيات:** المدير يحدد ما يظهر لكل دور (كاشير، ويتر، طباخ، سائق).
- **4 مظاهر:** زجاجي ملوّن، زجاج، داكن، فاتح.
- **الإعدادات:** بيانات المطعم، الفاتورة المطبوعة، التوصيل والمناطق، الصندوق، النسخ الاحتياطي.

## التشغيل
يحتاج فقط [Python 3](https://www.python.org/downloads/) بدون أي مكتبات إضافية.

```bash
py server.py
```
أو انقر مرتين على `تشغيل-الخادم.bat` على ويندوز.

ثم افتح على أي جهاز بنفس شبكة الواي فاي:
- لوحة الإدارة: `http://<عنوان-الجهاز>:8080/`
- تطبيق الويتر: `http://<عنوان-الجهاز>:8080/waiter.html`
- رموز QR للموبايلات: `http://<عنوان-الجهاز>:8080/connect.html`

البيانات تُحفظ في `data/state.json` (غير مرفوعة على GitHub).

## النسخة المنشورة على الإنترنت
يُنشر مجلد `prototype` تلقائياً على GitHub Pages مع كل رفع على `main`:
- لوحة الإدارة: `https://idontnowate.github.io/restaurant-system/`
- تطبيق الويتر: `https://idontnowate.github.io/restaurant-system/waiter.html`

يمكن تثبيت كل منهما كتطبيق على الموبايل والكمبيوتر (من قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»)، ويفتح بدون إنترنت.

## المزامنة بين الأجهزة
طريقتان، والنظام يختار تلقائياً:
1. **عبر الإنترنت (Supabase):** من لوحة الإدارة ← الإعدادات ← «المزامنة عبر الإنترنت» ← تفعيل. يظهر «رمز المطعم» ورموز QR؛ امسحها بموبايلات الويتر والأجهزة الأخرى. الطلبات والمنيو والطاولات تتحدث على كل الأجهزة خلال ثانيتين.
   - مرة واحدة فقط: شغّل `supabase/restaurant-sync.sql` في Supabase ← SQL Editor.
   - رمز المطعم سري: من يملكه يرى بيانات المطعم ويعدّلها.
2. **على شبكة المطعم (server.py):** بدون إنترنت، كل الأجهزة على نفس الواي فاي.

## هيكل المشروع
| الملف | الوصف |
|---|---|
| `server.py` | خادم محلي يربط كل الأجهزة ويحفظ البيانات |
| `prototype/admin.html` | لوحة الإدارة ونقطة البيع وشاشة المطبخ |
| `prototype/waiter.html` | تطبيق الويتر للموبايل |
| `prototype/connect.html` | رموز QR لربط الموبايلات |
| `prototype/core.js` | البيانات والمزامنة والأدوات المشتركة |
| `prototype/theme.css` | المظاهر والعناصر المشتركة |
| `prototype/pwa.js`، `sw.js`، `*.webmanifest`، `icons/` | التثبيت كتطبيق والعمل بدون إنترنت |
| `.github/workflows/pages.yml` | النشر التلقائي على GitHub Pages |
| `supabase/restaurant-sync.sql` | جداول ودوال المزامنة عبر الإنترنت |
| `prototype/vendor/` | مكتبة رموز QR (محلية لتعمل بدون إنترنت) |
| `docs/restaurant-needs.md` | تحليل احتياجات المطاعم وخطة البناء |
